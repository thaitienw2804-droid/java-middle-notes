- JVM: Java Virtual Machine, tầng trong cùng, thực thi bytecode (.class), quản lý bộ nhớ và GC.
- JRE: Java Runtime Environment, gồm JVM + thư viện core, dùng để chạy chương trình Java.
- JDK: Java Development Kit, gồm JRE + javac và công cụ phát triển, dùng để viết và biên dịch code.
